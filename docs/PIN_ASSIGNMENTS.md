# Pin Assignments for DE10-Standard Audio Visualizer

## Overview
This document details the pin assignments for the Audio Visualizer project on the DE10-Standard FPGA board.

## Pin Mapping Table

### Clock and Reset

| Signal | Pin | I/O Standard | Description |
|--------|-----|--------------|-------------|
| CLOCK_50 | AF14 | 3.3-V LVTTL | 50 MHz system clock input |
| KEY[0] | AA14 | 3.3-V LVTTL | Reset button (active low) |

### Switches (Channel Selection)

| Signal | Pin | I/O Standard | Description |
|--------|-----|--------------|-------------|
| SW[0] | AB30 | 3.3-V LVTTL | Channel select bit 0 |
| SW[1] | Y27 | 3.3-V LVTTL | Channel select bit 1 |

**Channel Selection:**
- 00: Left channel only
- 01: Right channel only
- 10: Average of both channels
- 11: Maximum of both channels

### Audio Codec Interface (WM8731)

#### Master Clock

| Signal | Pin | I/O Standard | Description |
|--------|-----|--------------|-------------|
| AUD_XCK | AC9 | 3.3-V LVTTL | Audio master clock output (12.288 MHz from PLL) |

#### I2S Audio Data

| Signal | Pin | I/O Standard | Direction | Description |
|--------|-----|--------------|-----------|-------------|
| AUD_BCLK | AE7 | 3.3-V LVTTL | Input | Audio bit clock from codec |
| AUD_ADCLRCK | AG30 | 3.3-V LVTTL | Input | ADC left/right clock (LRCLK) |
| AUD_ADCDAT | AC7 | 3.3-V LVTTL | Input | Audio ADC data (microphone input) |
| AUD_DACLRCK | AG3 | 3.3-V LVTTL | Output | DAC left/right clock (unused) |
| AUD_DACDAT | AH4 | 3.3-V LVTTL | Output | Audio DAC data (unused) |

#### I2C Configuration

| Signal | Pin | I/O Standard | Direction | Description |
|--------|-----|--------------|-----------|-------------|
| FPGA_I2C_SCLK | AH30 | 3.3-V LVTTL | Output | I2C clock for codec configuration |
| FPGA_I2C_SDAT | AF30 | 3.3-V LVTTL | Bidirectional | I2C data for codec configuration |

## WM8731 Configuration Details

### I2C Device Address
- 7-bit address: **0x1A** (0011010)
- With write bit: 0x34

### Register Configuration Sequence

| Step | Register | Address | Data | Description |
|------|----------|---------|------|-------------|
| 1 | R0 | 0x00 | 0x17 | Left Line In - default settings |
| 2 | R1 | 0x02 | 0x17 | Right Line In - default settings |
| 3 | R2 | 0x04 | 0x79 | Left Headphone Out - default |
| 4 | R3 | 0x06 | 0x79 | Right Headphone Out - default |
| 5 | R4 | 0x08 | 0x15 | Analog Path - Mic boost enabled |
| 6 | R5 | 0x0A | 0x06 | Digital Path - No soft mute |
| 7 | R6 | 0x0C | 0x00 | Power Control - All powered up |
| 8 | R7 | 0x0E | 0x01 | Digital Interface - I2S, 24-bit |
| 9 | R8 | 0x10 | 0x02 | Sampling - 48kHz, USB mode |
| 10 | R9 | 0x12 | 0x01 | Active - Activate digital interface |

## Clock Configuration

### Input Clocks
- **CLOCK_50**: 50 MHz main system clock

### Generated Clocks
- **AUD_XCK**: 12.288 MHz (generated by PLL from CLOCK_50)
  - Ratio: 50 MHz / 12.288 MHz ≈ 4.069
  - Used as master clock for WM8731 codec

### Audio Clocks (from WM8731)
- **AUD_BCLK**: ~3.072 MHz (64 × sample rate for 48kHz stereo)
- **AUD_ADCLRCK**: 48 kHz (sample rate)

## Signal Timing

### I2S Protocol Timing
- Data format: MSB-first, 24-bit samples
- Data valid on BCLK rising edge
- LRCLK transitions indicate channel (L/R)
- Each channel gets 32 BCLK cycles (24 data + 8 padding)

### I2C Protocol Timing
- Clock frequency: ~100 kHz (from 50 MHz system clock)
- START condition: SDAT falls while SCLK high
- STOP condition: SDAT rises while SCLK high
- ACK: Slave pulls SDAT low after 8 bits
- Data setup: 250 ns before SCLK rising edge
- Data hold: 0 ns after SCLK falling edge

## Testing Pin Locations

### Using an Oscilloscope or Logic Analyzer

**Recommended test points:**
1. **AUD_XCK (AC9)**: Verify 12.288 MHz clock output
2. **FPGA_I2C_SCLK (AH30)**: Monitor I2C configuration
3. **FPGA_I2C_SDAT (AF30)**: Monitor I2C data and ACK
4. **AUD_BCLK (AE7)**: Verify bit clock from codec
5. **AUD_ADCLRCK (AG30)**: Verify sample rate clock
6. **AUD_ADCDAT (AC7)**: Monitor audio data stream

### SignalTap Suggested Signals
- i2c_inst/state
- i2c_inst/ready
- i2s_inst/bit_count
- i2s_inst/sample_valid
- proc_inst/amplitude
- led_level[9:0]

## Notes

1. All pins use 3.3V LVTTL I/O standard
2. I2C pins (SCLK, SDAT) require pull-up resistors (typically on board)
3. Reset button (KEY[0]) is active-low
4. LEDs are active-high
5. The WM8731 codec is shared with other board components - ensure no conflicts
6. Audio input should be connected to MIC-IN port on the board
